# ผลทดสอบกู้คืน Mizuki Shop

ทดสอบวันที่ 8 กันยายน 2026 เวลา 00:00 น. (Asia/Bangkok) จากชุด `store_20260907_235659_1eb6e96f56b4`

## ผล: ผ่านการกู้คืนระดับฐานข้อมูลและไฟล์

- นำเข้า SQL จริงลงฐานข้อมูล MySQL ชื่อสุ่มที่สร้างใหม่ ใช้บัญชีชั่วคราวซึ่งมีสิทธิ์เฉพาะฐานข้อมูลนั้น ไม่แก้ .env หรือสลับฐานข้อมูลร้าน
- กู้คืน 26 ตาราง เปรียบเทียบ hash ของแต่ละแถวกับร้านปัจจุบัน ข้อมูลธุรกิจตรงกันทั้งหมด รวมยอด Wallet และประวัติซื้อ 2 รายการ
- ถอดรหัสข้อมูลบัญชีเกมและข้อมูลส่งมอบรวม 19 รายการด้วย APP_KEY เดิม โดยไม่แสดงข้อมูลลับในรายงาน
- คัดลอกรูปสาธารณะ 19 ไฟล์และสลิปส่วนตัว 1 ไฟล์เข้าโฟลเดอร์แยก ตรวจ SHA-256 ตรงกับชุดสำรอง และอ่านชนิด/ขนาดรูปสำเร็จ
- ตรวจเส้นทางรูปบัญชีเกมและสลิปจากฐานข้อมูล ไม่พบไฟล์หาย
- ข้อมูล session เปลี่ยนหลังเวลาสำรองตามการใช้งานเว็บ จึงรายงานความต่างแต่ไม่ถือเป็นข้อผิดพลาดการกู้คืน ตาราง sessions/cache/cache_locks ไม่ใช้ตัดสินความตรงกันของข้อมูลธุรกิจ
- ลบเฉพาะฐานข้อมูล บัญชี MySQL และไฟล์สำเนาชั่วคราวที่สร้างในการทดสอบเรียบร้อย ชุดสำรองและข้อมูลร้านเดิมคงอยู่ เก็บรายงานที่ `storage/app/restore-tests/report_56a5e85ab3cd.json`

## วิธีทดสอบซ้ำ

ใช้บนเครื่องผู้ดูแลเท่านั้น ต้องมี MySQL client และสิทธิ์สร้างฐานข้อมูล/ผู้ใช้ชั่วคราว:

```powershell
php scripts/verify-restore.php storage/app/backups/ชื่อชุดสำรอง
```

สคริปต์คืน exit code 0 เมื่อผ่าน และ 1 เมื่อไม่ผ่าน บันทึกรายงานโดยไม่ใส่ข้อมูลแถว รหัสผ่าน หรือ APP_KEY ให้ใช้เฉพาะชุดสำรองที่เชื่อถือได้บนเครื่องเดียวกับฐานข้อมูล XAMPP การเทียบกับร้านปัจจุบันจะต่างได้เมื่อมีรายการใหม่หลังสำรอง ไม่ได้แปลว่าไฟล์สำรองเสียเสมอไป หาก cleanup_required ปรากฏในรายงาน ผู้ดูแลต้องตรวจและล้างเฉพาะชื่อชั่วคราวที่ระบุ

## ขอบเขตที่ยังไม่ทดสอบ

ยังไม่ได้เปิดสำเนาหน้าเว็บเพื่อทำรายการซื้อ/เติมเงินจริง ไม่ส่งอีเมลหรือเรียกผู้ให้บริการชำระเงิน ไม่ได้พิสูจน์การกู้คืนบนโฮสต์ใหม่หรือกรณีเครื่องเดิมสูญหาย ตาราง products และ service_orders ยังไม่มีข้อมูลให้ตรวจกรณีรายการจริง ไม่รับรอง snapshot ระหว่างไฟล์กับฐานข้อมูล ณ เวลาเดียวกัน

ขั้นต่อไป: เตรียม staging แยกสำหรับทดสอบเส้นทางสมัครสมาชิก → เติมเงินทดสอบ → อนุมัติ → ซื้อสินค้า → รับข้อมูล โดยไม่ใช้เงินจริง แล้วจึงตั้งโดเมน HTTPS และ SMTP สำหรับ production
