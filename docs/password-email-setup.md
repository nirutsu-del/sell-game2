# การจัดการรหัสผ่าน

อัปเดต 19 กันยายน 2026: นำฟังก์ชันลืมรหัสผ่านทางอีเมลออกตามคำขอแล้ว

- ไม่มีลิงก์ลืมรหัสผ่านบนหน้าเข้าสู่ระบบ
- ยกเลิก routes ขอและรีเซ็ตรหัสผ่านทั้งหมด ลิงก์เก่าใช้งานผ่านเว็บไซต์ไม่ได้
- ผู้ที่เข้าสู่ระบบแล้วเปลี่ยนรหัสผ่านได้ที่ /account/password โดยต้องกรอกรหัสผ่านปัจจุบัน
- หลังเปลี่ยนต้องเข้าสู่ระบบใหม่ และ session/remember cookie เก่าถูกปฏิเสธ
- ไม่ต้องตั้ง SMTP สำหรับการจัดการรหัสผ่านนี้ การแจ้งเตือนร้านใช้ฐานข้อมูล

ยังเก็บตาราง password_reset_tokens ของ Laravel ไว้ ไม่มี endpoint ของร้านสำหรับสร้างหรือใช้ token เหล่านี้
