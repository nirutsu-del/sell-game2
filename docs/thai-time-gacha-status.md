# เวลาไทยและสถานะกล่องสุ่ม — 8 กันยายน 2026

- แปลงเวลาเฉพาะการแสดงผลเป็น Asia/Bangkok โดยใช้ copy() ก่อนแปลง ไม่เปลี่ยน APP_TIMEZONE หรือ timestamp ในฐานข้อมูล
- ครอบคลุมวันเผยแพร่ข่าว หน้าบัญชี แจ้งเตือน ประวัติคำสั่งซื้อ/งานบริการ ประวัติสุ่ม แดชบอร์ดแอดมินและกล่องข้อความ หน้าแอดมินเติมเงิน/ประวัติและรายงานยอดขายที่ใช้เวลาไทยอยู่แล้วคงเดิม
- เวลาแบบ “ที่ผ่านมา” แสดงภาษาไทย ส่วน datetime ISO ที่มี timezone สำหรับเครื่องอ่านยังคงรูปแบบเดิม เพิ่มข้อความระบุเวลาไทยท้ายหน้า
- ป้ายกล่องพิจารณาเฉพาะรางวัล drop_rate > 0 และไอดีที่ยัง available: เครดิตล้วนแสดง “พร้อมสุ่มรางวัลเครดิต”; ไอดีแสดงจำนวนที่เหลือ; แบบผสมเพิ่ม “+ รางวัลเครดิต”; ไม่มีรางวัลที่เข้าเงื่อนไขแสดง “รางวัลหมดชั่วคราว”
- ใช้ eligibleItems() ร่วมกันระหว่างรายการกล่องกับห้องสุ่มเพื่อให้ข้อมูลตรงกัน ไม่เปลี่ยนราคา เรท หรือวิธีตัดเครดิต ผลพร้อมสุ่มเป็นข้อมูล ณ เวลาที่เปิดหน้า เซิร์ฟเวอร์ยังตรวจรางวัลอีกครั้งเมื่อกดสุ่ม
