# สำรองและกู้คืนข้อมูล Mizuki Shop

ดูขั้นตอนกู้คืนและข้อควรระวังฉบับปัจจุบันในหัวข้อการสำรองและกู้คืนของ [production-security.md](production-security.md)

รัน `php artisan store:backup` เพื่อสร้างชุดชื่อไม่ซ้ำใน `storage/app/backups` โดยมี `database.sql`, `storage_public`, `private_slips` (ถ้ามี) และ `manifest.json` ไม่รวม `.env` ต้องเก็บ APP_KEY เดิมแยกอย่างปลอดภัยเพื่อถอดรหัสข้อมูลหลังการกู้คืน

รองรับ MySQL/MariaDB ต้องมี mysqldump ใช้ `--database-only` เพื่อข้ามไฟล์ หรือ `--output=D:\private-backups` เพื่อเก็บในโฟลเดอร์ส่วนตัวนอกโปรเจกต์ที่สร้างไว้แล้ว ชุดที่ล้มเหลวจะคงไว้ให้ตรวจสอบ ห้ามใช้ชุดที่ไม่มี manifest.json กู้คืน

กู้คืนในสำเนาโปรเจกต์และฐานข้อมูลทดสอบว่างเท่านั้น ห้ามนำเข้าทับร้านจริง ใช้คำสั่ง source ภายใน MySQL client ตามคู่มือที่เชื่อมไว้ด้านบน คัดลอกทั้งรูปสาธารณะและสลิปส่วนตัวกลับตำแหน่งเดิม

ควรเก็บชุดสำรองนอกเครื่องหรือในพื้นที่ที่จำกัดสิทธิ์ และทดสอบกู้คืนอย่างน้อยเดือนละครั้ง อย่าเผยแพร่โฟลเดอร์สำรองผ่านเว็บ เพราะอาจมีข้อมูลผู้ใช้และสลิปส่วนตัว
